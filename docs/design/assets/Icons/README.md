파비콘과 앱 아이콘입니다. 원본 마크를 줄인 것이 아니라, 16px 브라우저 탭을 기준으로 따로 설계한 **파비콘 마크** 하나에서 모든 크기를 만들었습니다.

## 형태와 뜻

물방울이 떨어진 수면을 위에서 내려다본 모습입니다. 위에서 본 물결은 동심원이 되고, 이 동심원은 LP의 홈과도 겹쳐 읽힙니다. 고리 두 개의 중심을 아래로 조금씩 내려서 위쪽은 가늘고 아래쪽은 네 배쯤 두껍습니다. 그래서 정지한 과녁이 아니라 아래로 빨려 들어가는 깊이로 읽힙니다. 원본 마크의 서사(소리 → 집중 → 몰입 → 울림 → 깊이) 가운데 '몰입 → 깊이'만 맡고, 소리(파형)는 원본 마크가 맡습니다. 브랜드 규칙 '물은 굵기가 변하는 면'을 그대로 따른 형태입니다.

- 오렌지는 점 하나뿐입니다(한 화면 한 오렌지).
- 점은 안쪽 고리 바닥에 닿아 있어야 합니다. 가운데로 올리면 눈(홍채와 동공)처럼 읽힙니다.
- 그라데이션, 테두리, 그림자, 회전을 더하지 않습니다. 비율도 바꾸지 않습니다.
- 고리 위쪽 굵기(바깥 2, 안쪽 1.2)는 16px에서도 원이 닫혀 보이게 하는 최소값입니다. 더 가늘게 하면 U자로 읽힙니다. 이 굵기 덕분에 작은 크기용 변형을 따로 두지 않습니다.
- 16px에서는 안쪽 고리 바닥과 바깥 고리, 점과 안쪽 고리가 겹쳐 아랫부분이 밝은 띠 하나로 뭉쳐 보입니다. 알고 받아들인 한계입니다.
- 파비콘과 앱 아이콘 자리 말고는 쓰지 않습니다. 동아리를 대표하는 자리(포스터, 슬라이드, 웹 헤더)에는 원본 마크나 워드마크를 씁니다.

## 파일

- `sounddive-favicon.svg` — 둥근 사각 바탕이 든 원본. 브라우저 탭 파비콘(SVG).
- `favicon.ico` — 16·32·48px를 담은 ICO. SVG 파비콘을 읽지 못하는 브라우저용.
- `favicon-16.png`, `favicon-32.png`, `favicon-48.png`, `icon-64.png` — 같은 그림을 크기별 PNG로 그린 것.
- `icon-192.png`, `icon-512.png` — 웹 앱 매니페스트용(둥근 사각 바탕).
- `sounddive-favicon-fullbleed.svg` — 모서리를 둥글리지 않고 바탕을 꽉 채운 판. 운영체제가 모서리를 직접 깎는 자리용입니다.
- `apple-touch-icon-180.png` — 위 판으로 그린 iOS 홈 화면 아이콘(iOS가 모서리를 둥글립니다).
- `icon-maskable-512.png` — 위 판으로 그린 안드로이드 마스커블 아이콘. 바깥 고리가 지름의 약 77% 안에 있어 원형 마스크(안전 영역 80%)에도 잘리지 않습니다.
