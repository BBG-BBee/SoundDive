모든 페이지 위에 고정되는 헤더로, 왼쪽에 워드마크, 오른쪽에 메뉴와 보조 버튼 하나를 둡니다.

## 만드는 쪽이 정하는 것
- 메뉴 항목: 3~4개의 짧은 한글(소개 · 활동 기록 · 함께하기).
- 현재 페이지: 해당 링크에 `aria-current="page"`(`ink` 글자 + `line` 밑줄). 오렌지로 표시하지 않습니다.
- 오른쪽 버튼(선택): 보조 버튼 작게(`sd-btn--secondary sd-btn--sm`). 첫 화면에 주 행동(오렌지) 버튼이 있으므로 헤더에는 오렌지를 두지 않습니다.
- 모바일 메뉴 열림 화면: `surface` 전체 화면에 메뉴를 `web-h2` 크기로 세로 나열합니다.

## 지킬 것
- 워드마크는 글자(Bricolage Grotesque 800)로 씁니다. 헤더 높이(60~72px)에서는 마크가 40px 안팎으로 작아져 봉우리가 붙어 보이므로 마크를 넣지 않습니다.
- 높이는 `header-height`(모바일 60px), 아래 경계는 `line-subtle` 1px. 반투명 배경·흐림 효과를 쓰지 않습니다.
