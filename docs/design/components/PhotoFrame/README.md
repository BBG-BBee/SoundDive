사진·캡처·QR을 담는 모서리 둥근 틀로, 비어 있을 때는 점선과 설명을 보여 주고 사진이 들어가면 점선이 사라집니다.

## 만드는 쪽이 정하는 것
- 크기와 비율: 사진은 4:3 또는 1:1, 화면 캡처는 16:9.
- 맞춤: 사진은 상자를 채우고(기본, cover), 화면 캡처·지도·QR은 잘리지 않게 `sd-frame--contain`.
- 캡션(선택): `sd-figure__caption`(`web-small`, `ink-muted`).
- 대체 글(alt): 무엇이 보이는지 한 문장.

## 사진 고르기
- 실제 활동 사진을 먼저 씁니다: LP카페·리스닝룸의 어둑하고 따뜻한 실내, 음반 재킷, 턴테이블, 스피커, 사람의 뒷모습이나 손.
- 카페 사진에서도 커피잔보다 음반과 사람이 주인공이 되게 고릅니다(커피 브랜드 연상 방지).
- 헤드폰을 끼고 웃는 스톡 사진, 음표 그래픽처럼 상투적인 장면은 쓰지 않습니다.
- 얼굴이 알아볼 수 있게 나오는 사진은 본인 동의를 받은 것만 씁니다.

## 지킬 것
- 모서리 `radius-frame`, 바탕 `surface-sunken`. 테두리·그림자는 두르지 않습니다.
- 사진 위에 글자를 얹지 않습니다. 글은 사진 밖(캡션이나 옆 문단)에 둡니다.
- 사진에 흐림·발광 효과나 강한 색 필터를 씌우지 않습니다.
