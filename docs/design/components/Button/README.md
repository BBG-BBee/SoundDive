행동을 요청하는 알약형 버튼으로, 화면에서 가장 중요한 행동 하나는 오렌지 면(주 행동), 나머지는 tan 테두리(보조)나 밑줄(글자 버튼)로 나눕니다.

## 쓰는 곳
- **주 행동** `sd-btn sd-btn--primary`: 지원하기, 소식 받기처럼 그 화면이 존재하는 이유인 행동. 한 화면(첫 화면 높이)에 하나만 둡니다. 면은 `accent`, 글자는 `on-accent`.
- **보조** `sd-btn sd-btn--secondary`: 둘러보기, 더 알아보기. 투명 바탕에 2px `line` 테두리, 글자 `ink`.
- **글자 버튼** `sd-btn sd-btn--text`: 카드나 문단 끝의 '자세히 보기'. 밑줄 2px `line`.
- **작게** `sd-btn--sm`: 헤더처럼 높이가 좁은 곳에만(40px). 그 밖에서는 48px를 지킵니다.

## 만드는 쪽이 정하는 것
- 글자: 동사로 끝나는 짧은 한 줄(`web-button`). 'OO하기' 형태를 권합니다. 이모지는 넣지 않습니다.
- 아이콘(선택): 오른쪽 화살표 하나. 2px 균일한 선, 둥근 끝(README의 아이코노그래피).
- 요소: 이동이면 `<a>`, 동작이면 `<button>`.

## 상태
- 마우스 올림: 주 행동은 오렌지를 그대로 두고 `ink` 테두리만 더합니다. 오렌지 색을 밝히거나 어둡게 바꾸지 않습니다. 보조는 `surface-raised` 면과 `ink` 테두리.
- 포커스: `:focus-visible`에 `focus-ring`. 바깥선(outline)을 지우려면 반드시 이 고리를 대신 둡니다.
- 비활성: 투명 바탕, `ink-muted` 글자, 점선 테두리. 반투명(opacity)으로 흐리게 만들지 않습니다.

## 하지 않는 것
- 오렌지 버튼 두 개를 나란히 두지 않습니다. 둘째는 보조로.
- 오렌지 면 위에 `ink`(cream)나 `ink-muted` 글자를 쓰지 않습니다(대비 2.3:1 이하).
- 그림자, 그라데이션, 발광 효과를 넣지 않습니다.
