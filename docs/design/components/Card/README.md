같은 종류의 항목을 나란히 비교하게 하는 테두리 카드로, 번호(영문 서체)·제목·분류·짧은 구분선·목록 순서입니다.

## 쓰는 곳
- 활동 종류, 일정 묶음, 장소 후보처럼 같은 모양의 항목이 2~4개 나란히 놓일 때.
- 모바일에서는 한 열, 768px부터 `sd-grid--3`(또는 `--2`)로 나란히 둡니다.

## 만드는 쪽이 정하는 것
- 번호(선택): 두 자리 숫자 `01`. Bricolage Grotesque 800, `ink-muted`.
- 제목(`web-h3`)과 분류(`web-label`): 분류는 한두 단어(방문, 공간 대여, 탐방).
- 목록: 3개 안팎, 한 줄씩. 문장 끝 마침표는 쓰지 않습니다.

## 지킬 것
- 테두리 2px `line`, 모서리 `radius-card`, 안쪽 여백 `space-32`. 강조가 필요한 카드 하나만 `sd-card--raised`(`surface-raised` 면).
- 카드 왼쪽에만 색 띠를 두르는 강조, 그림자, 그라데이션은 쓰지 않습니다.
- 카드 안에 오렌지를 쓰지 않습니다. 카드 묶음 전체의 초점이 필요하면 섹션의 주 행동 버튼으로 옮깁니다.
