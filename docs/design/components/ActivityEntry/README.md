모임 한 번을 한 장으로 남기는 기록 카드로, 사진 · 활동 종류 · 날짜 · 장소와 인원 · 제목 · 함께 들은 곡 · 한 줄 감상 순서입니다. SoundDive 웹사이트에서 가장 많이 쓰이는 단위입니다.

## 쓰는 곳
- 홈의 '최근 활동'(카드형 3개), 활동 기록 페이지(목록형 `sd-entry--row`), 인스타그램 게시물로 옮길 때의 원고.
- 처음 들어온 사람이 "이 동아리는 실제로 이런 곳에서 이런 음악을 듣는구나"를 알게 하는 근거가 됩니다.

## 기록 항목 (만드는 쪽이 채우는 것)
| 항목 | 예 | 규칙 |
| --- | --- | --- |
| 활동 종류 | LP카페 · 리스닝룸 · 음감회 · 탐방 | 정해진 이름 중 하나(`sd-entry__type`) |
| 날짜 | 2026.12.19 | `YYYY.MM.DD`, `<time>` 요소 |
| 장소 · 인원 | 망원동 LP카페 · 5명 | 가게 이름은 공개 영업장일 때만, 인원은 숫자만 |
| 제목 | 겨울 저녁, 재즈 피아노 한 장 | 그날의 주제를 한 줄로. 날짜나 '정기 모임 3회차' 같은 말은 쓰지 않음 |
| 함께 들은 곡 | 아티스트 — 곡명 | 1~5곡. 앨범이면 아티스트 — 앨범명 |
| 한 줄 감상 | …다르게 들렸다는 이야기가 많았습니다. | 존댓말 한두 문장, 개인 이름 없이 |
| 사진 | 공간, 음반, 손, 뒷모습 | 얼굴이 나오면 본인 동의를 받은 것만 |

## 지킬 것
- 카드 안에는 오렌지를 쓰지 않습니다. 활동 종류는 테두리 태그, 곡 목록 앞 표시는 짧은 `line` 선(소리의 선)입니다.
- 사진이 없으면 사진 자리를 비워 두지 말고 그 기록에서 사진 영역을 빼거나, 음반 재킷 사진으로 대신합니다.
- 미리보기의 날짜·장소·인원·감상은 모양을 보여 주기 위한 예시 데이터입니다.
