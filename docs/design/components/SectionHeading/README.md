섹션을 여는 머리 묶음으로, 작은 머리말과 제목, 그 아래 96px `line` 구분선이 한 세트입니다. 슬라이드의 제목 + 구분선과 같은 모양입니다.

## 만드는 쪽이 정하는 것
- 머리말(선택): 섹션 이름 한두 단어(`web-label`, `ink-muted`). 영문 대문자 머리말 대신 한글을 씁니다.
- 제목: 한 줄 안팎의 문장(`web-h2`, `ink`). 페이지 제목은 `web-h1`.
- 정렬: 읽는 섹션은 왼쪽 정렬(기본), 한 문장으로 말하는 소개·행동 섹션은 `sd-heading--center`.

## 지킬 것
- 구분선은 96px×`stroke-rule` 하나, 색은 `line`. 길이나 굵기를 바꾸지 않습니다. 포스터 락업의 140px 구분선은 첫 화면(Hero)에만 씁니다.
- 본문은 머리 묶음 아래 `space-48`에서 시작합니다.
- 제목 위치는 섹션마다 같은 자리(섹션 위 여백 바로 아래)에 둡니다.
