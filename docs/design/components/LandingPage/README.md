SoundDive 웹사이트 홈 예시로, 처음 들어온 사람이 1분 안에 "누가, 무엇을, 어떻게 하는 동아리인지"와 실제 활동 기록을 보게 하는 구성입니다. 이 시스템의 컴포넌트만으로 조립했습니다.

## 페이지 흐름(위에서 아래로, 마크의 서사 순서)
1. **헤더**(SiteHeader): 워드마크와 메뉴(소개 · 활동 기록 · 함께하기).
2. **첫 화면**(Hero): 소리 — 이름, 태그라인, 동아리를 정의하는 한 문장. 주 행동은 '활동 기록 보기' 하나(오렌지).
3. **소개**: 집중 — 누가 · 무엇을 · 어떻게 세 줄(`sd-facts`), 그 아래 한 문장 표제 "음악감상 = 음악 + 감상"(오렌지는 '감상' 한 곳).
4. **최근 활동 기록**(ActivityEntry ×3): 울림 — 실제로 모인 날들. 전체 기록 페이지로 가는 글자 버튼.
5. **함께하기**: 소식을 받는 경로(보조 버튼).
6. **푸터**(SiteFooter): 깊이 — 가장 어둡고 조용한 끝.

## 지킬 것
- 홈은 특정 기수나 행사(OT, 모집 일정)에 묶이지 않게 씁니다. 기수마다 바뀌는 내용은 활동 기록과 공지에 둡니다.
- 섹션 사이는 `space-96`(모바일 `space-64`), 머리 묶음과 본문 사이는 `space-48`.
- 오렌지는 한 화면 높이마다 한 곳입니다(첫 화면의 주 행동, 소개의 '감상').
- 미리보기의 기록 내용과 '인스타그램 열기' 같은 버튼 문구는 예시입니다.
