활동 기록을 모아 보는 페이지 예시로, 운영진이 모임이 끝날 때마다 한 건씩 쌓고 처음 온 사람은 위에서부터 훑어보며 동아리를 파악합니다.

## 구성
1. **페이지 머리**(`sd-pagehead`): 머리말 · 제목 · 이 페이지가 무엇인지 한 문장.
2. **거르기**(`button.sd-tag` + `aria-pressed`): 활동 종류별. 선택된 것은 `surface-raised` 면. 오렌지를 쓰지 않습니다.
3. **기수별 묶음**(`sd-archive__group`): "1기 2026 겨울"처럼 기수와 계절로 묶고, 안에서는 최신 기록이 위.
4. **기록**(`ActivityEntry`의 목록형).

## 지킬 것
- 기록은 최신순, 한 페이지에 한 기수씩. 기수가 쌓이면 이전 기수는 접거나 다음 페이지로 넘깁니다.
- 기록 하나하나의 쓰기 규칙은 `components/ActivityEntry/README.md`와 `02-web.md`의 '활동 기록 쓰기'를 따릅니다.
- 미리보기의 기록 내용은 예시 데이터입니다.
