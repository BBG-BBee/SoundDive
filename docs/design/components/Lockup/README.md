마크·워드마크·구분선·한글 보조 문구·행동 문구를 위에서 아래로 쌓은 SoundDive의 기본 배치입니다.

## 쓰는 곳

- **포스터 1080×1350**: 모집 공고(캠퍼스픽·링커리어)와 인스타그램 피드. 다섯 요소를 모두 씁니다.
- **썸네일 250×250**: 모집 플랫폼 목록 화면. 마크·워드마크·행동 문구만 씁니다. 250px에서 한글 보조 문구는 10px대로 작아지므로 빼고 공고 제목에 맡깁니다.
- **프로필 1080×1080**: 인스타그램 프로필. 마크만, 원 지름의 85~90% 안에 둡니다. 완성본은 `assets/Logos/sounddive-profile-1080.png`입니다.

## 만드는 쪽이 정하는 것

- 캔버스 크기와 배경: `backdrop-poster` 또는 `backdrop-profile`, 그 위에 그레인(`grain-opacity`, 썸네일은 `grain-opacity-thumb`).
- 마크: `assets/Logos/sounddive-mark.svg`를 비율 그대로(가로:세로 ≈ 0.92:1).
- 문구: 워드마크는 언제나 `SoundDive`. 한글 보조 문구는 한 줄(`kr-label`, `tan`), 행동 문구도 한 줄(`cta`, `signal-orange`)뿐입니다.

## 지킬 것

- 모든 요소를 가로 가운데 정렬하고, 간격은 README의 락업 표(`space-140`·`space-40`·`space-44`·`space-30`·`space-18`, 썸네일은 `space-16`·`space-4`·`space-10`)를 따릅니다.
- 오렌지 문구는 한 화면에 한 줄입니다. 두 번째 강조가 필요하면 `cream` 굵기로 처리합니다.
- 구분선은 140×`stroke-rule` `tan` 하나입니다. 선을 더 늘리거나 색을 바꾸지 않습니다.
- 밝은 바탕에는 이 배치를 그대로 올리지 않습니다(반전 버전 미정).
