짧은 분류나 주제를 알약 모양으로 묶는 태그로, 마크 선의 둥근 끝을 닮은 `radius-pill` 테두리입니다.

## 쓰는 곳
- 주제 나열(아이스브레이킹 질문, 장르, 장소 종류), 필터.
- 슬라이드의 알약형 태그와 같은 모양입니다.

## 만드는 쪽이 정하는 것
- 글자: 한두 단어. 문장을 넣지 않습니다.
- 선택 상태(필터일 때): `sd-tag--selected`(`surface-raised` 면 + `ink` 테두리). 오렌지로 선택을 표시하지 않습니다.
- 누를 수 있는 태그는 `<button>`으로 만들고 `focus-ring`을 둡니다.
