기간과 순서를 보여 주는 한 줄 타임라인으로, 균일한 `line` 선 위에 점을 찍고 지금 위치 하나만 오렌지로 표시합니다.

## 만드는 쪽이 정하는 것
- 항목: 3~6개. 각 항목에 이름(`sd-timeline__label`)과 짧은 설명(`sd-timeline__note`).
- 지금 위치: 한 항목에 `sd-timeline__item--now`(오렌지 점). 색만으로 알리지 않도록 설명에 '오늘'·'진행 중' 같은 말을 함께 씁니다.
- 아직 정해지지 않은 다음 단계: `sd-timeline__item--next`(속이 빈 점, 점선).
- 목록 자체에 `aria-label`로 무엇의 타임라인인지 적습니다.

## 지킬 것
- 선은 3px로 굵기가 일정하고 끝이 둥근 '소리의 선'입니다. 그라데이션이나 화살표 장식을 더하지 않습니다.
- 768px 미만에서는 세로로, 768px부터 가로로 놓입니다.
- 시험기간처럼 기간을 묶는 표시는 선 위쪽에 `ink-muted` 글자로 짧게 적습니다.
