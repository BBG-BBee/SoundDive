웹사이트 첫 화면으로, 포스터 락업(마크 → 워드마크 → 140px 구분선 → 한글 문구 → 행동)을 화면 폭에 맞게 다시 흘린 것입니다.

## 만드는 쪽이 정하는 것
- 한글 문구: 태그라인 "한걸음 더, 소리 속으로". 모집 기간에는 그 아래 `sd-cta`로 "1기 멤버 모집" 같은 한 줄을 더할 수 있습니다. 이때 오렌지 버튼은 두지 않고 보조 버튼만 둡니다(오렌지는 한 곳).
- 버튼: 주 행동 하나(`sd-btn--primary`) + 보조 하나까지.

## 지킬 것
- 바탕은 `sd-backdrop sd-grain`(`backdrop-poster` + 그레인 `grain-opacity`). 그레인은 바탕에만 걸고 글자 위에는 겹치지 않습니다.
- 마크 폭: 768px 이상 288px, 미만 176px. 마크를 늘이거나 자르지 않습니다.
- 모든 요소를 가운데 축에 맞춥니다. 첫 화면 높이 안에 버튼까지 보이게 합니다.
- 등장 효과는 `sd-rise`(위에서부터 100ms 간격, 500ms)만 씁니다. 마크 자체를 움직이거나 회전시키지 않습니다.
